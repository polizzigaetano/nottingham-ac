Button & CTA styling

Call-to-action buttons are created from an ordinary link. The text formatting you apply to the link decides how the button looks — there is no colour picker, so styles stay consistent with the brand. All buttons render as rounded pills automatically; you only choose the emphasis.

  • Bold link → Primary button — navy pill. Use for the main action.
  • Italic link → Secondary button — outlined navy pill. Use for a supporting action.
  • Bold and Italic link → Accent button — the high-impact pink pill (#d7336c). Use sparingly for the single most important action, such as “Apply now” or “Book your place”.

To make an accent CTA in the Universal Editor: select the link text and apply both Bold and Italic.
